# Phase 1 checkpoint: bundled framework content

Generated by `python3 tools/oscal_convert/checkpoint_report.py`, which uses a fixed random seed so the
samples are reproducible. Each sample links to the matching page in NIST's Cybersecurity and Privacy
Reference Tool (CPRT).

Independent cross-check against NIST CPRT's own JSON datasets (CSF 2.0, SP 800-53 Release 5.2.0,
SP 800-171 Rev. 3):

- SP 800-53: 1,014 active plus 182 withdrawn equals CPRT's 1,196 controls and enhancements. Every title
  matches, ignoring case and stray whitespace.
- SP 800-171: 97 active requirements and 33 withdrawn, as in CPRT. All 97 titles match. CPRT also lists
  88 organization-defined parameters, the same as the bundle.
- CSF 2.0: all 106 subcategory statements match CPRT word for word.

Published references that could not be represented, so they are excluded:

- CSF 2.0 → SP 800-53: `GV.OC-03 → PT`, `PR.IR-03 → CP`, and `PR.IR-03 → IR` point to whole control
  families, not single controls.
- CSF 2.0 → SP 800-53: `DE.AE-06 → RA-04` points to a control that is withdrawn in Release 5.2.0.
